# Simple-bash-script-to-generate-base64-passwords-
This bash script can generate any number of passwords wit any number of length of the base64 number system(other number systems can also be used by just replacing base64)
## INSTALLATION
```
git clone https://github.com/udaan793/Simple-bash-script-to-generate-base64-passwords-/edit/main/README.md
./pswrd.sh
```
## PRECAUTIONS
```
which $SHELL
```
check which shell is currently in use and replace it according to your own
